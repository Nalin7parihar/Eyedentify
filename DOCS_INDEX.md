## 📂 Project Files Overview

### Application Files
- [`app.py`](file:///home/nalin7parihar/Documents/Eyedentify/app.py) - Main Streamlit web application
- [`liveness_demo.py`](file:///home/nalin7parihar/Documents/Eyedentify/liveness_demo.py) - Command-line demo
- [`gather_examples.py`](file:///home/nalin7parihar/Documents/Eyedentify/gather_examples.py) - Training data collection script

### Model Files
- `liveness_model_v3.keras` - Main liveness detection model
- `liveness_model_colab_v3.keras` - Colab-trained variant
- `liveness_model_balanced_v2.keras` - Balanced dataset variant
- `le_model_v3.pickle` - Label encoder (v3)
- `le_colab_v3.pickle` - Colab label encoder
- `le_balanced_v2.pickle` - Balanced label encoder
- `detector/deploy.prototxt` - Face detector architecture
- `detector/res10_300x300_ssd_iter_140000.caffemodel` - Face detector weights

### Configuration Files
- [`requirements.txt`](file:///home/nalin7parihar/Documents/Eyedentify/requirements.txt) - Python dependencies
- [`pyproject.toml`](file:///home/nalin7parihar/Documents/Eyedentify/pyproject.toml) - Project metadata
